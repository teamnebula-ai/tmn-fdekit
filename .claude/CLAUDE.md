## Claude Code only

- To install the kit, use the plugin (`claude plugin marketplace add teamnebula-ai/tmn-fdekit`,
  then `claude plugin install tmn-fdekit@tmn-fdekit`). It brings the skills, the review agents
  and every hook. Full steps: `INSTALL.md`.
- To try a change to this repo live, run `claude --plugin-dir .` from the repo root.
- Don't install the plugin and also run `tmn-fdekit hooks`, or every hook fires twice.
